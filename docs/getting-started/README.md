# Getting started

Start here if you have not run hookspool before. The pages are in the order to read them.

| page | what it does |
|---|---|
| [Install](install.md) | what you need, and how to put the program on a machine |
| [Quick start](quick-start.md) | a five-minute local demo: send signed events, watch them become one delivery |
| [Your first bobbin](first-bobbin.md) | turn on a built-in bobbin for a real service, and try it offline |
| [From Hermes webhooks](from-hermes-webhooks.md) | move a Hermes gateway's webhook routes behind hookspool with no sender or prompt changes |
| [Verifying](verifying.md) | the checks that tell you the install and a sender are set up correctly |

When you are ready to run it for real, go to [Running hookspool](../operations/running.md). For the reasoning behind the design,
see [Architecture](../architecture/README.md).
